## 资产获取渠道梳理（两轮载具）

整理了资产获取渠道供后续使用：

- **首选 Fab**（UE 原生）：源码版引擎 Launcher 没引擎选项时，用 Fab 桌面客户端下载，或临时装 Launcher 版引擎中转
- **Sketchfab**：免费模型多但大部分没骨骼，需 Blender 自己绑
- **CGTrader / TurboSquid / ArtStation**：商用质量高，确认是否含 FBX 源文件
- **itch.io / GitHub / OpenGameArt**：独立开发者资源
- **动画**：车辆部分用物理驱动；骑手动画走 Mixamo + IK 重定向

## 选购检查清单（关键）

- 必须有 Skeleton（root + 两个 wheel bone）
- 必须确认 Forward Axis（UE 默认 +X）
- 必须有 FBX 源文件（只有 .uasset 改不了轴向）
- 是否带 Physics Asset
- License 是否允许商用
